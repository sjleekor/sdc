## 5. 판정과 한계

**S-4는 완료다.** 현재 생존 종목만 쓰면 price IC가 보통 수천분의 몇에서 최대 0.0067까지
달라진다. 앞으로 장기 가격 feature 검증은 복구 표본을 기본값으로 유지한다.

다만 이번 값은 하한이다.

- OHLCV가 없는 상폐-only 21개는 label을 만들 수 없어 두 표본 모두에서 빠졌다.
- `available`도 상폐 뒤 endpoint가 없으면 formation을 제외한다. 상폐 수익을 별도 terminal
  return으로 넣은 측정은 아니다.
- 현 시점 ACTIVE 필터는 의도적으로 미래 상태를 쓴 counterfactual 진단이다. 이 결과를
  feature 채택 통계나 새 BH 모집단으로 쓰지 않는다.
- IC 차이에 별도 permutation p-value를 붙이지 않았다. 이 문서는 편향 민감도와 크기를
  기록하며, 새로운 alpha 발견을 주장하지 않는다.
