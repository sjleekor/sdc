구분했지만, filing receipt는 법인별 `no_data` 키를 별도 ledger로 저장하지 않아
469개에 대한 연도별 사유를 raw만으로 복원할 수 없다. 따라서 문서에서 S-1을 최종
완료로 표시하기 전에 남은 확인은 filing receipt의 연도별 사유를 ledger로 남기는
일 하나다.

1. filing receipt 469개에 대해 2015~2026 전 연도 `stored/no_data/retryable` 판정을
   저장하거나, run별 no-data 응답을 보존하는 ledger를 만든다.
