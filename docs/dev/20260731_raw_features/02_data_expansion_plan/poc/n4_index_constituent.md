## 1. 확정된 사실 두 가지

### `date` 포맷은 `YYYYMMDD`다

docstring에 `YYMMDD`로 적혀 있어 계획이 미확정으로 뒀는데, 실측 결과다.

```
get_index_portfolio_deposit_file('1005', '20240102')  →  36 종목
get_index_portfolio_deposit_file('1005', '240102')    →  0 종목 (조용히 빈 값)
```

**틀린 포맷이 예외가 아니라 빈 리스트를 준다.** 어댑터에서 빈 응답을 성공으로 처리하면
전 구간이 조용히 비게 된다 — 테스트로 막아야 한다.

### 하한은 2014-05-01이다

```
20140602 → 36     20140502 → 36
20140401 → 0      "KRX web server does NOT provide data prior to 2014/05/01."
20130102 → 0      (같은 메시지)
```

**표본 시작(2014-06-02)보다 이르다.** 실질 손실이 없다는 계획의 판단이 맞았다.

## 2. ★ 상위 개념 지수를 골라내야 한다

지수 목록에 **포함관계가 섞여 있다.** 그냥 다 쓰면 한 종목이 여러 그룹에 들어간다.

| 지수 | 종목 수 | 관계 |
|---|---:|---|
| 1027 **제조** | 496 | **⊃ 전기전자(65) · 화학(104) …** |
| 1021 **금융** | 100 | **⊃ 증권(18) · 보험(11)** |
| 1013 전기전자 | 65 | ∩ 화학 = **0** |

- **제조 ⊃ 하위 11개 업종의 합집합(480).** 제조에만 있는 종목이 16개(기타제조)
- **금융 ⊃ 증권 ∪ 보험.** 나머지 71개가 은행 등
- **세부 업종끼리는 배타적이다** (전기전자 ∩ 화학 = 0)

> **따라서 상위 지수(제조·금융)를 빼고 세부 업종만 쓴다.**
> 다만 그러면 제조 잔여 16 + 금융 잔여 71 = **87종목이 어느 그룹에도 안 들어간다.**
> **코드에서 차집합 그룹 두 개(`기타제조`·`은행/기타금융`)를 정의**해 메운다.
> 지수가 아니라 코드로 만드는 그룹이므로 그 사실을 명시한다.

## 4. ★ 커버리지 — 이 경로의 약점 실측

2024-01-02 기준이다.

| 시장 | 배타 지수 합집합 | 상장 종목 | **커버리지** |
|---|---:|---:|---:|
| KOSPI | 743 | 953 | **78.0%** |
| KOSDAQ | 1,128 | 1,704 | **66.2%** |

**미편입이 KOSPI 22% · KOSDAQ 34%다.** §2의 차집합 그룹(87종목)을 더하면 KOSPI는
약 87%까지 오른다.

`05` §5의 표에 실측치를 넣으면 이렇게 된다.

| | N2 (DART `induty_code`) | N4 (KRX 업종 지수) |
|---|---|---|
| PIT | ✗ 현재 시점만 | **○ 시점별 실제 소속** |
| **커버리지** | **○ 99%+** (결측 0/150) | **✗ KOSPI 78% · KOSDAQ 66%** |
| 분류 깊이 | KSIC (2자리 조정 가능) | KRX 업종 (고정) |
| 하한 | 없음 | **2014-05-01** |

**둘은 대체가 아니라 보완이다.** 계획의 판단이 유지된다 — N2로 전 종목을 덮고,
N4로 PIT 약점을 측정한다.

**미편입 종목은 N2 업종을 폴백으로 쓰고 `industry_source` 컬럼으로 출처를 구분한다**
(`05` §5 권고). 마트에서 폴백 비율을 항상 같이 리포트한다. 이 비율이 22~34%로
작지 않으므로 **리포트가 선택이 아니라 필수다.**
