## V4 — `acc_mt != '12'` 시총 비중

`dart_corp_master.acc_mt`가 12월 결산이 아닌 법인은 전체 3,959개 중 142개다.
최신 저장 거래일인 2026-08-19의 `daily_market_cap`과 ticker를 조인하면 52개가
관측됐고, 이들의 합산 시총은 전체 ticker 시총의 **0.02361%**였다.

현재 표본에서 비12월 결산 법인이 시총 피처 전체를 좌우할 가능성은 작다. 다만
`period_end` 하드코딩을 바로 바꾸지는 않고, 법인별 결산월을 쓰는 variant가 필요한지
별도 검정에서 확인한다.

`now_to_isu_stock_totqy`와, 보고 기준일 이전 가장 가까운 `daily_market_cap.listed_shares`

| 사업연도 범위 | 2015~2025 |

다를 수 있어 모든 행이 일치하지 않는다. 따라서 V7은 `listed_shares`를 쓰는
`mcap_krx_log`의 정합성을 확인하는 보조 진단으로 닫고, DART 주식수를 거래소 값으로
대체하는 규칙은 만들지 않는다.
