## 2. ★ `0` sentinel — 실측 확정

2024-01-02 KOSPI 924행 기준이다.

| 컬럼 | 0인 행 | 비율 |
|---|---:|---:|
| BPS | 123 | 13.3% |
| **PER** | **314** | **34.0%** |
| **PBR** | **123** | **13.3%** |
| **EPS** | **314** | **34.0%** |
| DIV | 259 | 28.0% |
| DPS | 259 | 28.0% |

**정확히 짝을 이룬다.**

- `PER == 0` (314) ↔ `EPS == 0` (314)
- `PBR == 0` (123) ↔ `BPS == 0` (123)
- `DIV == 0` (259) ↔ `DPS == 0` (259)

`wrap.py`가 `'-'`를 `"0"`으로 치환하므로, **분자가 결측이면 비율도 0이 된다.**

### `PER == 0`은 적자기업이다

```
PER == 0 인 314종목 중 EPS <= 0 : 314   (전부)
                      EPS >  0 : 0
```

**예외 없다.** KRX가 적자기업의 PER을 `-`로 주고, pykrx가 그것을 0으로 만든다.

### 확정 정규화 규칙

`08` §A2의 잠정 방침을 조정한다.

| 컬럼 | 처리 | 근거 |
|---|---|---|
| `PER` | **0 → NULL** | 적자기업 = 결측 |
| `PBR` | **0 → NULL** | BPS 결측과 1:1 |
| `BPS` | **0 → NULL** | PBR과 짝. 진짜 0인 BPS는 없다 |
| `DIV` | **0 → NULL이 아니라 0 유지** | **무배당은 진짜 0이다** |
| `DPS` | **0 유지** | 같은 이유 |
| `EPS` | **0 유지** | 음수가 실제로 온다(적자). 0도 있을 수 있다 |

> **계획은 `DIV`도 0 → NULL로 넘기려 했는데 바꾼다.** 배당수익률 0은 결측이 아니라
> **무배당**이고, `ev_payout_yield`가 정확히 그 구분을 필요로 한다.
> `DPS`와 짝이 맞는 것(259 = 259)이 그 근거다.

`BPS`를 NULL 대상에 넣은 것도 계획 대비 변경이다 — PBR과 1:1로 맞아 결측 sentinel임이 확실하다.

## 4. ★ C3(I1 검증)의 답이 거의 나왔다

`08` §A5 C3의 질문은 이것이었다.

> `PER == 0`(결측 sentinel) 종목 = 적자기업. 그 집합이 I1의 "1분위 몰림" 집합과 겹치는가

| | 값 |
|---|---|
| KRX `PER == 0` 비율 (KOSPI 2024-01-02) | **34.0%** |
| `10_known_issues.md` **I1** — 구성요소 결측이 1분위로 대체된 행 비율 | **29.2%** |

**두 수치가 매우 근접하다.** I1은 "구성요소가 없는 종목이 그날 그 시장의 1분위 값으로
대체돼 전체 행의 29.2%가 가장 비싼 끝단에 몰린다"는 결함인데,
**적자기업이 E/P를 못 내는 것이 주요 원인이라는 가설과 정확히 맞는다.**

**다만 이건 하루·한 시장의 수치다.** 확정하려면 백필 후 전 구간에서
`PER == 0` 집합과 I1 대체 집합의 **교집합 비율**을 재야 한다. 그게 N7-8 C3다.
