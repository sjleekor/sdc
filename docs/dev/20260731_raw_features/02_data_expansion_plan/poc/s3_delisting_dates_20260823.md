## 해석과 제한

`stock_master.last_seen_date`는 상폐일이 아니다. 전체 455개 중 마지막 OHLCV 날짜와
같은 값은 25개뿐이고, 430개는 서로 달랐다. 상폐 이후 master snapshot 수집 시점과
마지막 거래일이 다르기 때문이다. 따라서 이번 결과의 `last_ohlcv_date`는
**가격이 실제로 관측된 마지막 날짜**로만 사용한다.

21개는 Naver가 해당 ticker의 가격을 반환하지 않았다. 이 종목은 S-2 실패로 보지 않고
`no_price_history`로 분리한다. 상폐일을 정확히 고정하려면 거래소 상폐 공시나 연속 PIT
snapshot이 추가로 필요하다.

## S-3 판정

S-2 가격 보강은 완료했다. A/B 입력에서는 455개를 historical OHLCV로 포함하고,
21개는 가격 label을 만들 수 없어 해당 날짜의 유효 표본에서 자연스럽게 제외한다.
상폐일을 `last_seen_date`로 소급해 쓰는 방식은 금지한다.
