# ev_payout_yield — 주주환원 수익률, 종목 단위 상세 조사

- family: `ev_payout_yield` (원천: `dart_shareholder_return_raw` + `daily_ohlcv`)
- 정의: `(현금배당총액 + 자사주매입현금)_ttm / 시가총액` — 최근 1년 동안 회사가
  주주에게 돌려준 현금이 시총의 몇 %인지.
- 기대 방향: `+` (많이 돌려주는 회사가 이후 초과수익이 높다,
  Boudoukh et al.(2007)) / 관측 방향: `+` (일치)
- 등급: **B** — 통계가 아니라 **원천 품질**(정정 비율 0.1146 > 임계 0.10)이
  A를 막았다.
- 대상 run: Phase B `20260812T231507-f9117ce1` + 결합 AB `20260813T130307-f9117ce1`
  (snapshot `2026-08-12`, config `e55c3046…`). **[01](01_px_reversal_5d.md)~[06](06_px_amihud_20d.md)이
  인용한 Phase A run과 다른 실행이므로 숫자를 직접 비교하면 안 된다.**
- 상위 문서: [../09_all_feature_results.md](../09_all_feature_results.md) §8

## 0. 쉬운 설명 (먼저 읽기)

한 줄 결론: **배당과 자사주 매입으로 현금을 많이 돌려준 회사가 이후 더 나았다.**
통계는 T2에서 `fin_log_mcap` 다음으로 강한데, 등급이 B에 묶인 이유는 통계가 아니라
데이터 품질이다. 용어가 막히면 [07_glossary.md](07_glossary.md)를 보면 된다.

### 0.1 이 피쳐가 재는 것

배당수익률의 확장판이다. 배당만 보면 자사주를 사서 소각하는 회사가 저평가되기
때문에, **자사주 매입에 쓴 현금까지 합쳐서** 시총으로 나눈다. 값이 0.04면 시총의
4%를 지난 1년간 주주에게 돌려줬다는 뜻이다.

기대 방향이 `+`인 근거는 두 가지다. 현금을 돌려줄 수 있다는 것 자체가 이익의
질을 보여주고, 고배당주는 요구수익률이 높은 경향이 있다.

### 0.2 §1 통계표 — 통계는 강한데 등급은 B다

| 숫자 | 뜻 |
|---|---|
| IC +0.0972 (누적 120일) | T2에서 `fin_log_mcap` 다음으로 크다. NW t는 오히려 더 큰 셀도 있다. |
| 4개 셀 전부 q≈0 | 통계적 유의성은 의심할 여지가 없다. |
| revision_ratio 0.1146 | **A를 막은 것은 이 숫자 하나다.** 임계 0.10을 근소하게 넘었다. |
| placebo p=0.178 / 0.267 | 강건성 요구를 받은 3개 셀은 **전부 실패**했다. |

여기가 이 family의 두 얼굴이다. **IC도 ICIR도 `fin_log_mcap`에 밀리지 않고 NW t는
더 큰데, 시계열을 통째로 밀어놓고 만든 가짜 신호와 구분되지 않는다.** 이 게이트는
효과의 크기가 아니라 **시점 정렬이 진짜인지**를 묻는다
([../09_all_feature_results.md](../09_all_feature_results.md) §9.2).

살아남은 셀은 40–60일 bucket 하나이고, 그건 폭이 20일이라 애초에 강건성 검사
대상이 아니었다.

### 0.3 §2 — 절반 가까이가 0이다

값의 **42.8%가 정확히 0**이다. 배당도 자사주 매입도 하지 않은 회사다. 그래서
하위 4개 분위는 전부 "0인 종목들"이고 그 안의 순서에는 의미가 없다.

§2에서는 10분위 대신 **수익률 구간**으로 나눴다. 그렇게 보면 깔끔하다 —
환원 없음 -0.21%에서 8% 초과 +0.18%까지 올라가고, 상승 비율도 43.8%에서
49.1%로 5.3%p 높아진다.

### 0.4 §3 종목 사례

2025-05-02 기준 상위 15종목이 초과수익 평균 **+0.19%**, 하위 15종목이 **-1.39%**
로 방향이 맞는다. 다만 40~60일 사이 20거래일짜리 구간이라 크기 자체는 작다.

### 0.5 §4 — 데이터에 남아 있는 잡티

세 가지가 있다.

- **극단값**: 최댓값이 21,603이다. 시총의 216만 %를 환원했다는 뜻이 되므로 분모
  쪽 오류가 거의 확실하다.
- **음수**: 9개 종목 1,513행에서 값이 음수다. 자사주 처분이 매입 현금을 음수로
  만들거나, 배당 총액 자체가 음수로 들어온 경우다.
- **정정**: `treasury_share_acquisition_amount`의 정정 비율이 임계를 넘어 등급이
  B로 묶였다.

공식 IC는 순위 기반이라 극단값에 영향받지 않는다. 하지만 **이 값을 그대로 선형
모델에 넣으면 한 종목이 계수를 지배한다.** 채택 단계에서 윈저라이즈가 필수다.

### 0.6 최종 위치

T2에서 두 번째로 강한 통계를 가졌지만, 장기 셀이 시계열 placebo를 통과하지
못했고 원천 정정 비율이 임계를 넘었다. 배당 데이터 정정분을 다시 받은 뒤
재검증하는 게 순서다.

## 4. 데이터 품질 — 등급을 B로 묶은 것이 여기다

**정정 비율.** `treasury_share_acquisition_amount`(자사주 취득금액)의 정정
비율이 0.1146으로 임계 0.10을 넘었다. 같은 사업연도 값을 나중에 고쳐 다시
공시하는 비율이 11%를 넘는다는 뜻이다. PIT 규칙상 당시 공시본을 쓰므로 정정
자체가 미래 정보 누수는 아니지만, **원본이 자주 바뀐다는 사실 자체가 신뢰도
문제**로 취급된다. `fin_value_z`도 같은 이유로 B다
([11_fin_value_z.md](11_fin_value_z.md)).

**극단값.** 최댓값이 21,603(2,160,300%)이다. 특정 종목의 2016년 11~12월
관측치들이 이 수준으로 몰려 있어, 그 시기 시가총액 분모가 잘못 잡혔을
가능성이 높다. 분포는 중앙값 0.0041, 상위 1% 0.1347, 상위 0.1% 0.5137이라
0.5를 넘는 순간 이미 꼬리다.

**음수.** 9개 종목 1,513행에서 값이 음수다. 확인해 보면 두 경로다 —
자사주 매입 현금이 음수(성호전자 -77.8억)이거나, 현금배당 총액 자체가
음수(코스텍시스 -3.4억)다.

세 가지 모두 **rank IC에는 영향이 없다.** 하지만 이 피쳐를 회귀·부스팅 모델에
넣을 때는 윈저라이즈와 음수 처리 규칙을 먼저 정해야 한다.
